# Carmine

Carmine is a virtual makeup engine that applies lipstick, blush, and eyeshadow to a face in real time while preserving skin texture and lighting instead of flattening it into a solid mask. It tracks facial landmarks in the browser and renders the result directly over a live camera feed, so you can see makeup on your own face as a mirror rather than a static photo filter. The core blending pipeline is Python, with a lightweight web front end driving the real-time camera loop.
